# Material Accumulation — тестовое задание Unity Developer

## Описание проекта

Прототип механики накопления материала на поверхности с использованием Unity и C#.

Накопление реализовано путём изменения геометрии одного Mesh. Пользователь управляет зоной воздействия, внутри которой материал постепенно добавляется к поверхности. Ранее накопленный материал сохраняется, а повторные и пересекающиеся проходы увеличивают существующую высоту.

## Реализованный функционал

- Перемещение зоны накопления с помощью WASD.
- Накопление материала при удержании Space.
- Плавное циклическое изменение радиуса через `AnimationCurve`.
- Настройка скорости движения, радиуса, амплитуды, частоты и скорости накопления через Inspector.
- Непрерывное накопление вдоль траектории движения, включая высокую скорость.
- Суммирование материала при повторных и пересекающихся проходах.
- Сброс поверхности клавишей R.
- Обработка только затронутой области сетки для уменьшения количества вычислений.

## Архитектура

### TerrainMesh.cs

Отвечает за создание и обновление геометрии поверхности.

При запуске генерирует регулярную сетку из вершин и треугольников. При изменении высот обновляет координаты вершин Mesh, пересчитывает нормали и границы геометрии.

### HeightMap.cs

Хранит состояние накопленного материала в отдельном массиве `float[]`.

Каждому индексу вершины соответствует значение высоты. Данные накопления не зависят от визуального представления Mesh.

### AccumulationZone.cs

Отвечает за управление зоной, анимацию радиуса и расчёт добавляемого материала.

При перемещении вычисляет промежуточные точки траектории и применяет накопление в каждой из них.

## Алгоритм накопления

Поверхность представлена регулярной сеткой. Для каждой вершины хранится её текущая высота.

В пределах зоны используется полусферический профиль распределения накопления:

`factor = sqrt(1 - distance² / radius²)`

Количество добавляемого материала:

`addedHeight = accumulationSpeed × deltaTime × factor`

Полученное значение прибавляется к текущей высоте вершины.

Таким образом, материал накапливается постепенно, существующая геометрия не уменьшается, а повторные проходы увеличивают высоту.

Полусферический профиль определяет интенсивность добавления материала в зависимости от расстояния до центра зоны, а не абсолютное ограничение итоговой высоты поверхности.

### Непрерывность следа

Для предотвращения разрывов между кадрами используется интерполяция между предыдущим и текущим положениями зоны.

Траектория разделяется на промежуточные шаги с учётом размера ячейки сетки. Время кадра распределяется между этими шагами, поэтому накопление учитывает `Time.deltaTime`.

Радиус также интерполируется между предыдущим и текущим значениями.

### Оптимизация

Вместо перебора всех вершин на каждом промежуточном шаге рассчитываются границы затронутой области сетки.

В основном цикле накопления не создаются новые массивы или списки. Обновление Mesh выполняется после обработки траектории.

## Управление

| Клавиша | Действие |
|---|---|
| W / A / S / D | Перемещение зоны |
| Space (удерживать) | Накопление материала |
| R | Сброс поверхности |

## Запуск проекта

1. Открыть проект в Unity 6 с Universal Render Pipeline (URP).
2. Открыть основную сцену из папки `Assets/Scenes`.
3. Нажать Play.
4. Использовать клавиши управления.

Для текущей реализации ввода необходимо включить `Active Input Handling = Both` либо поддержку Legacy Input Manager.

## Ограничения реализации

- Используется Height Map с фиксированным разрешением, поэтому геометрия не поддерживает нависающие поверхности и полости.
- Накопление основано на полусферическом распределении интенсивности, без физической симуляции частиц.
- После изменения геометрии нормали пересчитываются для всего Mesh.
- Визуальный индикатор показывает область воздействия, но не является точной трёхмерной полусферой.

## Возможные улучшения

- Частичное обновление изменённых участков Mesh.
